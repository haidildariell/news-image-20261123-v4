Bounty: [Sum up 23 November's world news in one image](https://make.fun/bounty/news-image-20261123) on make.fun.

A one-page newspaper front page for Monday 23 November 2026, generated by a
single self-contained Python program. It carries 34 real stories from that
day across 6 continents: four lead cards (Nvidia's +33% day, Ukraine's drone
strike at Benghazi, the COP31 collapse in Antalya, the Democrats' 258-seat
House majority), eight mid-size cards, a "Where It Happened" world map with
22 pins, and 22 more stories in the "Also on Monday" column. A date-check
strip on the page lists the off-day items that were discarded.

## How it works

`main.py` uses only the Python 3.13 standard library. It opens no file for
reading: the three typefaces are embedded in the program as base64, decoded
in memory, and rendered by a small TrueType engine written for this entry
(cmap/glyf parsing, outline rasterizer, 3x supersampling). The only output
is `/output/entry.png`, a deterministic 1024x1024 PNG.

Run it with:

    python3 main.py
